# AK — Clothing Brand E-Commerce

Premium fashion store built with pure PHP. Full cart, checkout, orders, admin panel, multi-theme.

## Quick Setup (Laragon)

1. Copy folder to `C:\laragon\www\ak`
2. DocumentRoot must be `C:\laragon\www\ak\public`
3. Import **one file**: `database/install.sql` in phpMyAdmin
4. Open `http://ak.test`

### Features
- 20 clothing products with sizes & colors
- Categories: Men, Women, T-Shirts, Shirts, Pants, Jackets, Hoodies, Accessories
- Shopping cart (session)
- Checkout with COD / bKash / Nagad / Card
